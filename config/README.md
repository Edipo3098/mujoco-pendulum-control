# Configuration

Los parámetros físicos nominales del Cart-Pole ideal se encuentran en [cartpole-parameters.yaml](cartpole-parameters.yaml).

**Importante:** son valores de referencia provisionales. Todavía no existe un modelo MJCF ni un cargador C++/Python que consuma esta configuración; este archivo por sí solo no configura MuJoCo.

Los parámetros del futuro MJCF deberán contrastarse con las hipótesis del modelo analítico. Los ajustes de control y de experimentos se añadirán conforme avancen las implementaciones.
