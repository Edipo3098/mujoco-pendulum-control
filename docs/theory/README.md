# Theory notes

Documentación matemática del Cart-Pole ideal, ordenada por etapas:

1. [01 — Dynamic Models](01-dynamic-models.md): convenciones, cinemática, energías, Euler–Lagrange, dinámica matricial y espacio de estados no lineal.
2. [02 — Linearization and Lyapunov's Indirect Method](02-linearization-and-stability.md): equilibrios, perturbaciones, Taylor, jacobianos, valores propios e inestabilidad en lazo abierto.

Los parámetros nominales provisionales están en [config/cartpole-parameters.yaml](../../config/cartpole-parameters.yaml). La validación con MuJoCo, la controlabilidad y el LQR siguen pendientes; consultar el [roadmap](../ROADMAP.md).
